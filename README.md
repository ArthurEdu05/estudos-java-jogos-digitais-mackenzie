# Projeto Asteroids — Desenvolvimento com Java e libGDX  

Este repositório contém o projeto incremental desenvolvido para a disciplina **Jogos Digitais** da **Universidade Presbiteriana Mackenzie**, no qual implementei um jogo 2D inspirado no clássico **Asteroids**, utilizando **Java** e o framework **libGDX**.

O projeto teve como objetivo aplicar, na prática, os principais fundamentos de análise, design e desenvolvimento de jogos digitais estudados ao longo da disciplina, desde conceitos teóricos até a implementação completa de mecânicas, colisões, física, áudio e estruturação do jogo.

---

## 📚 Contexto Acadêmico

Durante a disciplina, estudamos:

- Conceitos básicos, histórico e mercado de jogos digitais.  
- Estruturas fundamentais de jogos, mecânicas e elementos (itens, personagens, enredo).  
- Processo de produção de jogos digitais e documentação (One Page Document, storyboard, level design).  
- Programação gráfica 2D, estados de objetos e estruturação da gameplay.  
- Programação de áudio e física aplicada a jogos.  
- Implementação prática usando **Java + libGDX**.

Este projeto consolida todos esses tópicos por meio de um jogo funcional com movimentação, física, colisões, lógica de gameplay e renderização gráfica.

---

## 🕹️ Sobre o Jogo

O jogo segue a lógica clássica do **Asteroids**:

- O jogador controla uma nave espacial em um ambiente 2D.  
- Asteroides diversos e itens de Boost surgem e se movimentam pelo cenário com física simples.    
- Asteroides e itens desaparecem ao serem atingidos e cada um possue sua lógica de efeito.  
- O jogo detecta e trata colisões entre:  
  - Nave e asteroides diversos 
  - Nave e itens benéficos  
- Sons são reproduzidos para ações e colisões.
